
# 🛒 Online Shopping and Order Processing System (Python OOP)

## 📌 Project Overview

This project is a console-based Online Shopping and Order Processing System developed using Python Object-Oriented Programming concepts.

The application allows users to:

- Manage product inventory
- Add products to a shopping cart
- Update or remove cart items
- Generate invoices
- Apply customer-specific discounts
- Calculate GST
- Process payments

The project demonstrates core OOP principles including encapsulation, inheritance, polymorphism, abstraction, and exception handling.

---

## Features

### Product Management

- Add products
- Prevent duplicate Product IDs
- Search products
- Display products sorted by price

### Inventory Management

- Track stock availability
- Automatically reduce stock after purchase
- Restore stock when cart items are removed

### Shopping Cart

- Add items
- Update quantity
- Remove items
- Validate stock availability

### Customer Types

- Regular Customer (5% Discount)
- Premium Customer (10% Discount)
- VIP Customer (20% Discount)

### Billing System

- Calculate subtotal
- Apply discounts
- Calculate 18% GST
- Generate invoice
- Payment validation
- Balance calculation
